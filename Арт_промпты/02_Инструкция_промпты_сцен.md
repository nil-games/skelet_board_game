# Инструкция: как писать промпты конкретных картинок

Мастер-промпт ([01_Мастер-промпт_стиль.md](01_Мастер-промпт_стиль.md)) отвечает за то, **как нарисовано**. Этот документ отвечает за то, **что нарисовано и почему это смешно**. Вы пишете только блок `Scene:`, всё остальное подставляется из мастер-промпта без изменений.

---

## 1. Тон: главный приём

Игра — юмористическое фэнтези про мёртвых пиратов, которые ведут себя как живые офисные сотрудники, туристы, блогеры и соседи по коммуналке. Живые их почти не замечают, чайки вымогают налоги, экзорцисты неприлично бодры.

**Главный комический приём: эпичная подача бытовой ерунды.** Стиль у нас пафосный: драматичный свет, героические позы, контровое свечение. Смешно становится, когда этой подачей рисуют планёрку, очередь к кофемашине или спор о том, кто доел суп. Персонажи относятся к абсурду **абсолютно серьёзно**.

Три источника шутки (в одной картинке хватает одного-двух):

| Источник | Как выглядит | Пример |
|---|---|---|
| **Анахронизм** | Современная вещь или ритуал в пиратском мире. Вещь может быть настоящей или «собранной» из пиратского хлама | Канбан-доска из стикеров, прибитая к мачте. Ноутбук из сундука и ракушек |
| **Гипербола** | Мультяшно преувеличенная реакция, размер, количество | Челюсть отвалилась и катится по палубе. Стопка счетов выше мачты |
| **Перевёрнутая роль** | Кто-то ведёт себя не так, как положено | Чайки-налоговые инспекторы. Морское чудище стесняется. Экзорцисты как аниматоры на корпоративе |

## 2. Формула блока `Scene:`

Пишите по-английски, в этом порядке, 60–120 слов:

1. **Кто** — персонажи с их постоянными приметами (из раздела 4). Не больше 4 значимых фигур.
2. **Что делают** — одно главное действие + поза. Глаголы движения.
3. **Шутка** — главный гэг одной фразой: что именно смешного видит зритель.
4. **Эмоции** — через глаза-огоньки, челюсть, позу (см. словарь в разделе 5).
5. **Где** — место и 2–3 детали окружения, работающие на шутку.
6. **Свет и акцент** — откуда свет, какой цвет главный (бирюза / золото / маджента).
7. **Композиция** — план и ракурс: что на переднем плане, куда смотрит глаз.

Шаблон:

```
Scene: [WHO with fixed traits] [DOING main action, pose].
The gag: [one sentence — what is funny at first glance].
[Emotions via eye-glow, jaw, posture].
Setting: [place], [2–3 details that support the gag].
Lighting: [source], main accent [teal / gold / magenta].
Composition: [shot size, camera angle, foreground / background].
```

---

## 3. Правила

**Делаем**
- **Один главный гэг на картинку.** Если шуток три, нейронка нарисует кашу. Вторичные шутки — мелкие детали фона, не больше двух.
- **Шутка читается без подписи и за 2 секунды** на экране телефона.
- **Современные отсылки через узнаваемые архетипы и ситуации**: планёрка, дедлайн, кофемашина, open space, бейдж на шнурке, селфи, распродажа, курьер, техподдержка, тимбилдинг, фитнес-браслет, доставка еды, «вы нам перезвоните».
- **Поп-культура — через позу, ситуацию или жанровый штамп**, а не копию персонажа: «pose like a famous movie poster of a sinking ship romance», «dramatic slow-motion walk away from an explosion like in action movies», «heist crew lineup».
- **Мультяшная гипербола анатомии скелетов**: кости отваливаются и возвращаются, черепа крутятся на 180°, челюсть падает буквально.
- **Жестокость только мультяшная**: шишки, звёздочки, разлетевшиеся кости. Скелеты бессмертны, им не больно, им неловко.

**Не делаем**
- **Текст в картинке.** Нейронки ломают буквы, особенно кириллицу. Вывески, таблички, бумаги рисуем пустыми или с пиктограммами (`blank sign`, `sticky notes with doodles instead of text`). Надписи при необходимости добавляем потом в редакторе.
- **Реальные бренды, логотипы, знаменитости, персонажи чужих франшиз.** Игра пойдёт в печать. Вместо «Starbucks cup» пишем `generic takeaway coffee cup`, вместо конкретной звезды — архетип («smug tech-startup CEO in a black turtleneck»).
- **Хоррор и реалистичную анатомию.** Никаких трупов, плоти, крови. Скелеты милые, чистые, кость цвета слоновой кости.
- **Длинные описания фона.** Фон в стиле упрощён и затемнён, лишние детали съедят внимание модели.
- **Изменение стиля внутри `Scene:`.** Не пишите «watercolor», «realistic», «pixel art» и т. п.: это ломает серию.

## 4. Каст: постоянные приметы скелетов

Копируйте описание **дословно** в каждый промпт, где персонаж участвует. У каждого фиксированные: силуэт, цвет-код и **одна современная вещь** (фирменный анахронизм).

| Скелет | Вставка в промпт |
|---|---|
| **Костолом** | `Bonebreaker — a massive broad-shouldered skeleton with comically oversized forearm bones, red bandana, torn striped sailor vest, a modern gym sweatband on one wrist, carries a protein shaker; color code crimson.` |
| **Картограф** | `the Cartographer — a tall thin lanky skeleton with round brass spectacles on the skull, navy long coat covered in ink stains, quill tucked in an ear hole, rolled maps under the arm, a modern lanyard ID badge; color code navy blue.` |
| **Поэт-ужасатель** | `the Horror Poet — a dramatic slender skeleton in a black turtleneck under a frilly poet's shirt, long purple scarf, black beret, holds a quill and a battered notebook, a takeaway coffee cup always nearby; color code violet.` |
| **Стрелок** | `the Gunslinger — a cool lean skeleton in a long dark duster coat and wide-brimmed pirate hat with a feather, twin flintlock pistols, modern aviator sunglasses over the eye sockets; color code dark teal.` |
| **Кладоискатель** | `the Treasure Hunter — a short stocky skeleton with an oversized backpack, a shovel, a modern headlamp strapped over a tricorn hat, carries a modern metal detector; color code mustard yellow.` |
| **Корабельный кок** | `the Ship's Cook — a round-bellied skeleton (belly is an empty barrel strapped to the ribs) in a tall stained chef's toque and apron, giant ladle, quilted oven mitt on one hand; color code orange.` |

Второстепенные персонажи мира (тоже держать единообразно):

| Персонаж | Вставка |
|---|---|
| Чайки | `chubby smug seagulls with tiny accessories (reading glasses, clipboards, little caps), human-like gestures` |
| Живые люди | `living humans drawn slightly more mundane and less saturated, oblivious to the skeletons` |
| Экзорцисты | `overly cheerful exorcists in matching bright team t-shirts and lanyards, wide fake smiles, holy-water spray bottles like a cleaning crew` |
| Призрачный корабль | `the crew's ghost ship — black weathered wood, torn teal-glowing sails, brass lanterns with teal flame` |

> Новых постоянных персонажей добавляйте в эту таблицу: описание пишется один раз и дальше только копируется.

## 5. Словарь эмоций скелета

У черепа нет лица, поэтому эмоции нужно называть явно, иначе модель нарисует пустой череп.

| Эмоция | Как написать |
|---|---|
| Шок | `eye-glows blown wide into big circles, jaw dropped so far it detaches` |
| Паника | `eye-glows shrunk to tiny dots, cartoon sweat drops flying off the skull, limbs flailing` |
| Подозрение | `eye-glows narrowed to thin slits, one brow ridge raised, leaning in` |
| Самодовольство | `eye-glows as smug half-closed crescents, chin up, arms crossed` |
| Радость | `eye-glows as happy upturned crescents, jaw wide open in a grin, bones rattling` |
| Скука / выгорание | `dim half-lidded eye-glows, skull resting on hand, slumped spine, a tiny ghost-fire flickering out` |
| Влюблённость / восторг | `heart-shaped eye-glows` |
| Ярость | `eye-glows burning magenta, ghost-fire flaring from the skull` |

## 6. Примеры

### Событие: налоговая проверка от чаек (SCENE, 3:2)

```
Scene: Three chubby smug seagulls in tiny reading glasses audit the Treasure Hunter (short stocky skeleton, oversized backpack, headlamp over a tricorn hat, metal detector) on the ghost ship deck. One gull stamps a blank document with a huge official stamp, another counts gold coins with its wing, the third points at the open treasure chest.
The gag: a skeleton pirate being bullied by a seagull tax inspection like a terrified small business owner.
The Treasure Hunter clutches a pile of crumpled receipts, eye-glows shrunk to tiny dots, cartoon sweat drops flying off the skull.
Setting: ghost ship deck at night, open treasure chest, a tiny folding desk the gulls brought with them.
Lighting: golden glow from the chest from below, teal lantern rim light.
Composition: medium shot, low angle from behind the gulls, the skeleton cornered against the mast.
```

### Событие: утренняя планёрка (SCENE, 3:2)

```
Scene: The Cartographer (tall thin skeleton, round brass spectacles, ink-stained navy coat, lanyard ID badge) leads a daily stand-up meeting, pointing at a kanban board nailed to the mainmast covered in sticky notes with doodles instead of text. Bonebreaker (massive skeleton, oversized forearms, red bandana, gym sweatband) and the Horror Poet (black turtleneck, purple scarf, beret) hold coffee mugs.
The gag: the epic cinematic lighting of a war council applied to a boring office stand-up.
The Cartographer is fully serious, eye-glows sharp. The Poet is asleep standing up, his jaw slowly sliding off. Bonebreaker squints at the board in confusion.
Setting: deck at dawn, teal-glowing torn sails, a coffee pot hanging from the rigging.
Lighting: dramatic teal backlight from the sails, warm gold from the coffee.
Composition: heroic low angle, the Cartographer in the foreground like a general.
```

### Враг: бодрые экзорцисты (ENEMY, 3:2)

```
Scene: A squad of four overly cheerful exorcists in matching bright yellow team t-shirts and lanyards storms the ghost ship, doing a team high-five while spraying holy water from spray bottles like a cleaning crew.
The gag: exorcism done with the energy of a corporate team-building event.
Huge fake smiles, thumbs up, one exorcist filming a selfie video. In the foreground two skeletons hide inside barrels, only their panicked tiny-dot eye-glows visible.
Setting: ghost ship deck, a holy-water mist rainbow over the scene.
Lighting: obnoxiously bright sunny light from the exorcists' side clashing with the dark teal ship.
Composition: wide diagonal composition, exorcists invading from top-right, barrels in the lower-left foreground.
```

### Портрет: Корабельный кок (PORTRAIT, 2:3)

```
Scene: The Ship's Cook — a round-bellied skeleton (belly is an empty barrel strapped to the ribs) in a tall stained chef's toque and apron, giant ladle, quilted oven mitt — poses like a celebrity TV chef, tasting soup from the ladle with dramatic pride, while the soup leaks straight through his jaw and ribs onto the floor.
The gag: he can't actually taste anything, but acts like a food critic.
Eye-glows as smug half-closed crescents, chin up.
Setting: steaming cauldron, hanging fish and garlic.
Lighting: orange fire glow from below, teal rim light.
Composition: waist-up, three-quarter view.
```

### Предмет: компас, который ведёт к кофе (ITEM, 1:1)

```
Scene: An ornate brass pirate compass with a skull engraving, its needle bent into the shape of a tiny steaming coffee cup, glowing teal runes around the dial, a small ghostly coffee steam swirl rising from it.
The gag: a magic navigation tool that only finds coffee.
Lighting: golden highlights on brass, teal glow from the needle.
Composition: centered, three-quarter angle.
```

## 7. Мета-промпт для LLM

Чтобы ChatGPT / Claude превращал текст события из приложения в готовый блок `Scene:`, дайте ему этот текст вместе с этим файлом:

```
Ты пишешь промпты для генерации иллюстраций к юмористической настольной игре про скелетов-пиратов на проклятом корабле. Стиль картинок уже задан отдельным мастер-промптом — НЕ описывай стиль, рисовку, цвета техники. Пиши только блок "Scene:" на английском, 60–120 слов, строго по шаблону:

Scene: [WHO with fixed traits] [DOING main action, pose].
The gag: [one sentence].
[Emotions via eye-glow, jaw, posture].
Setting: [place + 2–3 details for the gag].
Lighting: [source], main accent [teal / gold / magenta].
Composition: [shot size, angle, foreground/background].

Правила:
- Один главный гэг, понятный без подписи за 2 секунды. Приём: эпичная подача бытовой ерунды, анахронизмы из современной жизни (офис, соцсети, доставка, фитнес, бюрократия), мультяшная гипербола, перевёрнутые роли.
- Скелетов описывай ДОСЛОВНО по таблице каста (вставлю ниже). Эмоции — через словарь глаз-огоньков.
- Никакого текста в картинке (вывески и бумаги пустые или с рисунками), никаких реальных брендов, логотипов, знаменитостей и чужих персонажей — только архетипы.
- Никакого хоррора и крови, насилие только мультяшное.
- Не больше 4 значимых фигур.

Дай 3 варианта с разными гэгами, затем отметь, какой считаешь самым смешным и читаемым.

Каст: [вставить таблицу из раздела 4]
Событие: [вставить title + flavor из приложения]
```

---

## 8. Порядок работы

1. Сгенерировать 6 скелетов пресетом **FULLBODY**, выбрать лучших, сохранить как референсы персонажей.
2. Сделать 3–5 сцен, отобрать эталон стиля (см. мастер-промпт, раздел 7).
3. Дальше штамповать события: текст события → мета-промпт → `Scene:` → сборка с мастер-промптом → генерация → чек-лист приёмки.
4. Каждое новое правило, найденное на практике («модель путает X с Y», «лучше писать так»), записывать сюда.
