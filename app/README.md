# Приложение «Всем костям на борт!» (телефон, офлайн)

Тексты событий, портов и боёв **не правятся здесь**: они живут в генераторе `03_Прототип/_генератор/content.py`
(тот же источник, что у буклета и Книги событий). После правки контента:

```
cd app
npm run content   # экспорт в public/game_data.json с проверкой; при ошибке файл не меняется
npm test          # тесты движка
npm run dev       # локально: http://127.0.0.1:5173
```

Публикация: пуш в `main` → GitHub Actions (`.github/workflows/pages.yml`) пересобирает контент, гоняет тесты и выкладывает на GitHub Pages.

Структура: `src/engine/` — правила (чистые функции, тесты рядом), `src/screens/` — экраны, `src/store.ts` — сохранения на телефоне.
